# Evidence

Text evidence for `SCORECARD.md` and `ROUNDS.md`, by round (`rN-`). Local
paths are replaced by `<repo>`, `<GOMODCACHE>`, `<sigiro-src>` and `~`.
Screenshots of the sigiro dashboard used as the test receiver are not
included (sigiro is not open source); the dashboard checks they backed are
summarised in `rN-summary.txt` and the `rN-*.json` files next to them.
